# Scorecard

Harsh, evidence-based. Planned work gets no credit. Anything that needs the founder's accounts, domain, traction or
a real network path to Open Charge Map / Overpass / Nominatim / CARTO is marked **founder action** and is scored
only for what the code and docs can prove.

**Total: 81 / 100 verified. 19 points are not earned**, and most of them need the founder or live infrastructure.
This is not "100/100" and does not predict a YC interview: nobody can promise that.

## How this was measured

Commands run in the build sandbox on the final tree: `npx prettier --check .`, `npm run lint`, `npm run typecheck`,
`npm test`, `npm audit`, `npm run build`, `npx playwright test` (desktop + mobile projects, Chromium), and Lighthouse
12 (mobile preset, headless, software WebGL, so performance numbers are pessimistic and not comparable to a real
device). The browser walk-through of `/` and `/map` is the Playwright suite (console errors collected on the landing
page and the main map flow, on both projects). In the sandbox the real CARTO basemap is unreachable, so map tests
stub the basemap and the registry; those stub stations are synthetic and test-only.
